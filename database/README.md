# Banco de dados da COMPET

A COMPET usara MySQL. Esta pasta guardara scripts SQL versionados, como a criacao do banco e das tabelas.

## Planejamento

1. Definir os requisitos e as entidades necessarias.
2. Desenhar o modelo entidade-relacionamento.
3. Criar o script `schema.sql` com tabelas, chaves primarias e chaves estrangeiras.
4. Testar o script localmente antes de integrar a API.

O esquema definitivo ainda nao foi criado. Nao coloque dados pessoais reais nem senhas neste repositorio.
