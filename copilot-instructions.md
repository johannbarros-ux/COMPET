
# Instruções do projeto

- Explique as alterações em português brasileiro.
- Preserve o código existente sempre que possível.
- Não reescreva arquivos inteiros para corrigir um problema pequeno.
- Não altere funcionalidades que não foram solicitadas.
- Antes de editar, identifique a causa do problema.
- Ao ensinar, explique o código para um iniciante.
- Não adicione bibliotecas sem necessidade.
- Informe quais arquivos foram modificados.
- Não invente funções, arquivos ou requisitos.
