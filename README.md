# COMPET

Projeto acadêmico de desenvolvimento web, orientado pelo professor Danilo, do IFPB — Campus Campina Grande. O objetivo é criar uma plataforma para incentivar a adoção e a doação responsável de animais.

## Estado atual

O projeto está em desenvolvimento. A interface usa HTML, CSS e JavaScript. O back-end e a integração com MySQL ainda serão implementados por etapas.

## Organização atual

- `index.html`: página inicial.
- `css/`: estilos.
- `js/`: JavaScript do front-end.
- `paginas/`: páginas do site.
- `imagens/`: imagens utilizadas no site.
- `backend/`: planejamento futuro da API em Node.js e Express.
- `database/`: documentação e futuros scripts SQL do MySQL.
- `docs/`: documentação técnica e acadêmica.

## Próximas etapas

1. Finalizar e testar as páginas existentes.
2. Definir os requisitos e o modelo do banco de dados.
3. Criar a API usando Node.js e Express.
4. Integrar a API ao MySQL.
5. Testar e documentar as funcionalidades.

## Segurança

Não publique senhas, tokens ou credenciais no repositório. Configurações locais devem ficar em um arquivo `.env`, ignorado pelo Git. Use `.env.example` apenas como modelo sem segredos reais.
