# Documentacao da COMPET

Esta pasta reunira a documentacao tecnica e academica do projeto, por exemplo:

- requisitos funcionais e nao funcionais;
- diagramas de casos de uso e entidade-relacionamento;
- decisoes de arquitetura;
- plano e resultados de testes;
- material que possa apoiar a elaboracao futura do TCC.

Registrem aqui as decisoes reais do grupo, em vez de documentar funcionalidades que ainda nao foram implementadas.
